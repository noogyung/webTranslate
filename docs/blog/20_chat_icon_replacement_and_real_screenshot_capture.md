## 1. 요구 사항과 이유 (Requirement & Why)

### 요구 이유
크롬 웹 스토어에 등록할 그래픽 에셋(아이콘, 스크린샷)을 준비하는 과정에서 2가지 문제에 부딪혔다:
1. 기존 아이콘이 '번역'이 아니라 '채팅 말풍선' 모양에 가까워, 스토어 방문자들에게 번역 도구라는 정체성을 전달하지 못함.
2. AI 에이전트가 크롬 웹 스토어용 스크린샷(1280x800)을 생성형 AI로 그려오겠다고 시도하여, 실제 프로그램 UI와 전혀 다른 가짜 이미지로 심사 거절 위험 초래.

### 요구 사항
1. 글로벌 번역 도구의 직관적인 느낌을 주는 16px, 48px, 128px 고해상도 공식 아이콘을 제작하여 적용할 것.
2. AI가 만들어낸 가짜 이미지를 전면 배제하고, 실제 웹사이트(Steam, MDN 등)에서 WebTranslator가 작동하는 1280x800 실물 스크린샷을 준비할 것.

---

## 2. 지시 내용 (Instruction)

AI에게 아이콘 교체 및 스크린샷 정리를 지시했다:

> **"아이콘이 번역보다는 채팅에 어울린다. 번역에 어울리는 아이콘으로 전면 교체하고, AI로 가짜 이미지를 만들지 말고 `images/` 폴더에 찍어둔 1280x800 실제 동작 스크린샷을 등록해라."**

---

## 3. AI의 구현 결과 및 발생한 시행착오 (Trial & Error)

AI가 처음에 미드저니/DALL-E 풍의 AI 생성 이미지를 스토어 스크린샷으로 등록하려 했다.

### 발생한 문제점
* **스토어 심사 정책 위반**: 구글 크롬 웹 스토어는 실제 확장 프로그램의 UI가 아닌 가상의 과장된 AI 그래픽을 올릴 경우 허위 마케팅으로 심사를 반려함.

## 5. 해결 과정 및 결과 (Resolution)

AI가 실제 스크린샷 메타데이터와 공식 아이콘을 `manifest.json`에 완벽히 연동했다.

```json
// manifest.json
"icons": {
  "16": "icons/icon16.png",
  "48": "icons/icon48.png",
  "128": "icons/icon128.png"
},
"action": {
  "default_icon": {
    "16": "icons/icon16.png",
    "48": "icons/icon48.png",
    "128": "icons/icon128.png"
  }
}
```

* **준비된 스토어 실물 스크린샷 목록 (1280x800)**:
  1. `screenshot_1.png`: Steam 상점 페이지 1:1 인라인 번역 및 레이아웃 보존 화면
  2. `screenshot_2.png`: 단어 드래그 시 0.8초 만에 뜨는 발음/품사/예문 사전 카드
  3. `screenshot_3.png`: 다크모드 사이트에서의 환경 적응 보색 렌더링 화면
  4. `screenshot_4.png`: 툴바 빠른 설정 팝업(슬라이더 글자 크기 실시간 조절)

심사관이 보아도 한눈에 프로그램의 동작을 신뢰할 수 있는 완벽한 시각 자료가 갖춰졌다.

## 6. 다음 작업 사항과 이유 (Next Work & Why)

그래픽 에셋까지 모두 준비되었으나, 구글 개발자 대시보드에서 `permissions`에 들어간 권한들에 대한 엄격한 소명 요구가 쏟아졌다.

**개발 편의로 넣어두었던 불필요한 부가 권한들을 전면 삭제하고, `permissions: ["storage"]` 단 하나만 남기는 최소 권한 다이어트를 완수해야겠다.**
