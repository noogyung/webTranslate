## 1. 요구 사항과 이유 (Requirement & Why)

### 요구 이유
사이트마다 글씨 크기를 110%로 키우거나 하이라이트 배경 투명도를 바꾸고 싶을 때가 많았다. 하지만 기존에는:
1. 확장 프로그램 아이콘 우클릭 ➔ 옵션 페이지 새 탭 열기
2. 옵션 탭에서 설정 변경 후 저장
3. 원래 보던 탭으로 돌아와서 새로고침

이 3단계를 거쳐야 했고, 웹서핑의 집중을 심각하게 깨뜨렸다.

### 요구 사항
1. 브라우저 우상단 확장 프로그램 아이콘 클릭 시 현재 웹페이지를 벗어나지 않고 즉시 열리는 미니 빠른 설정 팝업(`optionPopup.html`)을 만들 것.
2. 잘 쓰지 않는 복잡한 옵션(화면 내 지연 번역 등)은 과감히 빼고, **글자 크기(85%~120%) 슬라이더, 하이라이트 투명도 슬라이더, 번역 엔진 선택**만 핵심으로 배치할 것.
3. CSS Custom Properties(`--wt-font-size-ratio`)를 적용하여 슬라이더를 움직이는 즉시 웹페이지에 실시간 반영될 것.
4. 옵션 창과 팝업 창 내의 기본 `<select>` 드롭다운을 세련된 커스텀 드롭다운 디자인으로 전면 통일할 것.

---

## 2. 지시 내용 (Instruction)

AI에게 툴바 빠른 설정 팝업 개발과 드롭다운 스타일 통일을 지시했다:

> **"대형 옵션 페이지로 이동하지 않고 툴바 아이콘 클릭 시 슬라이더로 크기와 투명도를 실시간 조절하는 `optionPopup.html`을 신설하고, 체크박스 커스텀 드롭다운 스타일로 전체 드롭다운 디자인을 통일해라."**

---

## 3. AI의 구현 결과 및 발생한 시행착오 (Trial & Error)

AI가 코드를 작성했으나 UI 일관성이 깨져 있었다.

```html
<!-- AI가 작성한 드롭다운 UI (불일치) -->
<!-- 한쪽은 브라우저 기본 투박한 회색 select 태그 -->
<select id="engineSelect"><option>Google</option></select>
<!-- 다른 쪽은 커스텀 CSS 드롭다운 -->
<div class="custom-dropdown">...</div>
```

### 발생한 문제점
* **UI 파편화**: 팝업창 내부의 드롭다운과 본체 옵션 페이지의 드롭다운 스타일이 제각각이라 조잡해 보이고 통일감이 결여됨.

---

## 4. 지시 번복 및 지시 보완 (Action: Reversal & Supplement)

* **[지시 번복 - 대형 options.html 중심의 조작 방식 폐기]**:  
  > "설정 하나 바꿀 때마다 새 탭 여는 방식은 전면 폐기한다. **모든 일상적인 스타일 조작은 툴바 미니 팝업(`optionPopup.html`)에서 1초 만에 끝나도록 메인 UI를 툴바 팝업으로 교체해라.**"
* **[지시 보완 - 커스텀 드롭다운 디자인 전면 통일]**:  
  > "기본 `<select>` 태그를 그대로 두지 마라. **모든 선택 메뉴를 세련된 커스텀 드롭다운 UI(`custom-select`) 컴포넌트로 일괄 교체하여 모던한 디자인 룩앤필을 완성해라.**"

## 5. 해결 과정 및 결과 (Resolution)

AI가 CSS 변수 기반의 실시간 렌더링 엔진과 통일된 팝업 UI를 완성했다 (`commit: 1720da9`).

```css
/* content.css */
:root {
  --wt-theme-color: #818cf8;
  --wt-trans-bg: rgba(129, 140, 248, 0.12);
  --wt-font-size-ratio: 100%;
}

.wt-translation {
  font-size: var(--wt-font-size-ratio) !important;
  background-color: var(--wt-trans-bg) !important;
}
```

```json
// manifest.json
"action": {
  "default_title": "Web Translator 빠른 설정",
  "default_popup": "optionPopup.html"
}
```

웹서핑 중 툴바 아이콘을 클릭하고 슬라이더를 슥 당기는 것만으로 웹페이지의 번역문 글자 크기가 실시간으로 커졌다 작아지는 극상의 편의성을 확보했다.
