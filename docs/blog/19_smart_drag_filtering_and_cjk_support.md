## 1. 요구 사항과 이유 (Requirement & Why)

### 요구 이유
크롬 웹 스토어 배포 직전 최종 실전 테스트를 하던 중 어이없는 버그가 발견되었다. 국내 한국어 블로그나 뉴스 기사에서 문장을 복사하려고 마우스로 긁는 순간, **단어 번역 팝업창이 마우스 커서를 가로막으며 툭 튀어나왔다.**

이미 한국어로 적힌 글을 복사하려는데 번역기를 돌리려 하니 웹서핑에 엄청난 방해가 되었다.

### 요구 사항
1. 사용자의 목표 언어가 한국어(`ko`)일 때, 한국어 문장을 드래그하면 팝업을 절대 띄우지 않을 것.
2. `Apple (사과)`처럼 괄호 안에 한국어 번역이 병기된 외국어 단어를 드래그했을 때는 정상적으로 사전을 띄울 것.
3. 일본어(한자/히라가나/가타카나), 중국어 단어도 알파벳처럼 정확하게 인식할 것.

## 2. 지시 내용 (Instruction)

AI에게 드래그 유효성 검사 필터 고도화를 지시했다:

> **"현재 드래그로 문단 번역을 했을 경우 이미 목표 언어(한국어)임에도 번역이 일어나는 일이 있다. 드래그한 텍스트에 목표 언어 비율이 10% 이상인 경우 목표 언어로 판정하여 사전을 스킵하도록 적용해라."**

---

## 3. AI의 구현 결과 및 발생한 시행착오 (Trial & Error)

AI가 코드를 수정해 가져왔으나, 2가지 엣지 케이스에서 문제가 터졌다.

```javascript
// AI가 작성한 1차 필터링 로직 (오류 코드)
if (text.includes("한글")) return false; // 한글 1글자라도 있으면 무조건 스킵!
```

### 발생한 문제점
1. **괄호 병기 단어 검색 불가**: `Apple (사과)`처럼 외국어 단어 옆에 한국어 뜻이 작게 병기된 단어를 드래그하면, 한글이 1글자 들어있다는 이유로 사전 팝업이 차단됨.
2. **CJK 유니코드 인식 불가**: 정규식을 `[a-zA-Z]`로만 짜놓아서, 일본어 단어(`日本語`)나 중국어 단어를 드래그하면 "단어가 아님"으로 판정하여 사전을 띄우지 못함.

## 4. 지시 수정 및 지시 보완 (Action: Fix & Supplement)

* **[지시 수정 - 10% 비율 임계값(Threshold) 판정 도입]**:  
  > "한글 1글자 기준은 취소다! **전체 문자열 중 한글 글자 수가 10% 이상일 때만 모국어 문장으로 판정하고, 10% 미만인 경우는 `Apple (사과)`처럼 보조 설명이 붙은 외국어로 보아 정상적으로 사전을 열도록 임계값을 완화해라.**"
* **[지시 보완 - 최신 유니코드 속성 `\p{L}` 정규식 보정]**:  
  > "`[a-zA-Z]` 구식 정규식을 버려라. **전 세계 모든 언어의 문자를 인식하는 최신 정규식 유니코드 속성 `\p{L}`과 한자/가나 범위를 적용해 CJK 다국어 단어를 100% 인식하도록 보완해라.**"

## 5. 해결 과정 및 결과 (Resolution)

AI가 지능형 사전 필터 `isValidDictWord`를 완성했다 (`commit: da044fc`).

```javascript
// src/content/filter.js
export function isValidDictWord(text, targetLang = "ko") {
  if (!text || typeof text !== "string") return false;
  const str = text.trim();

  // 1. 공백 및 너무 긴 텍스트 차단 (300자 초과)
  if (str.length === 0 || str.length > 300) return false;

  // 2. 순수 숫자, 가격($49.99), 날짜 스킵
  if (/^[\d\s.,:;!?'"()/\-–—%#$€¥₩+*=@&]+$/.test(str)) return false;

  // 3. API Key, Hash, Token 형태 차단
  if (/^(?:sk-[a-zA-Z0-9_\-]{20,}|ghp_[a-zA-Z0-9]{20,}|AIzaSy[a-zA-Z0-9_\-]{30,})$/.test(str)) return false;

  // 4. 목표 언어가 한국어일 때 10% 임계값 검사
  if (targetLang.startsWith("ko")) {
    const hangulMatches = str.match(/[\uAC00-\uD7AF\u1100-\u11FF\u3130-\u318F]/g) || [];
    const hangulRatio = hangulMatches.length / str.length;
    // 한글이 10% 이상이면 이미 한국어 문장이므로 스킵! (Apple (사과)는 통과)
    if (hangulRatio >= 0.1) return false;
  }

  // 5. 전 세계 모든 문자(CJK 포함) 최소 1글자 포함 확인
  return /[\p{L}\p{N}]/u.test(str);
}
```

한국어 사이트에서 글을 복사할 때는 팝업이 전혀 방해하지 않고, 영문 단어 및 일본어/중국어 단어를 드래그했을 때만 0.8초 만에 정확하게 사전을 띄우는 극상의 스마트 드래그 UX가 완성되었다.
