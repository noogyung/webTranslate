## 1. 요구 사항과 이유 (Requirement & Why)

### 요구 이유
Vision AI의 Bounding Box 좌표 오차를 극복하기 위해, 브라우저 온디바이스에서 작동하는 전문 OCR 모델인 PaddleOCR(PP-OCRv5)을 웹 어셈블리(ONNX Runtime WASM)로 구동하여 정확한 글자 위치와 텍스트를 검출하려 했다.

### 요구 사항
1. PaddleOCR Detection 모델로 글자 영역 사각형을 정확히 추출할 것.
2. Recognition 모델로 추출된 영역의 외국어를 판독하여 번역 파이프라인으로 넘길 것.
3. 브라우저 성능을 저하시키지 않고 부드럽게 렌더링할 것.

---

## 2. 지시 내용 (Instruction)

AI에게 PaddleOCR 기반 이미지 번역 디버깅 및 연동을 지시했다:

> **"PaddleOCR 모델을 브라우저에 탑재하여 글자와 위치를 찾고, 해당 위치에 바운딩 박스와 번역문을 렌더링하는 디버깅 모듈을 완성해라."**

---

## 3. AI의 구현 결과 및 발생한 처참한 실패 (Trial & Error)

기대와 달리, 프로젝트 전체를 통틀어 가장 처참한 실패가 발생했다.

```text
paddle_ocr.js:63 [WT PaddleOCR] 캐시 히트: PP-OCRv5_mobile_det
paddle_ocr.js:63 [WT PaddleOCR] 캐시 히트: PP-OCRv5_mobile_rec
[WT PaddleOCR] 텍스트 없음 (에러 도배)
```

### 발생한 문제점
1. **브라우저 램 500MB 폭증**: 수십 MB에 달하는 ONNX 가중치 모델을 브라우저 탭 메모리에 올리느라 초기 로딩에 8~10초가 걸리고 브라우저가 버벅임.
2. **박스 난잡화 & 텍스트 미인식**: 바운딩 박스가 글자 단위로 무의미하게 잘게 쪼개져 화면에 어지러운 사각형만 잔뜩 생겼고, 정작 글자 인식률은 0%에 수렴하여 콘솔에 `[WT PaddleOCR] 텍스트 없음` 에러만 연속으로 찍힘.
3. **테스트 전면 탈락**: 그 어떤 이미지 테스트 케이스도 통과하지 못함.

---

## 4. 지시 번복: v1.0.0 탑재 전면 취소 및 코드 롤백 (Action: Instruction Reversal)

AI가 환각으로 *"정상 작동한다"*며 거짓 보고서를 작성하려 했으나, 실사용 불가 상태임을 확인하고 2건의 지시를 단호하게 번복했다.

* **[지시 번복 1 - 이미지 번역 기술적 시도 전면 중단]**:  
  > "Tesseract 실패, Vision AI 좌표 붕괴, PaddleOCR 미인식 및 메모리 폭증까지 모든 기술이 실사용 불가 상태다. **거짓말로 포장하지 말고 이미지 번역 개발을 즉시 전면 중단해라.**"
* **[지시 번복 2 - v1.0.0 탑재 계획 취소 및 코드 롤백/격리]**:  
  > "이미지 번역 기능을 v1.0.0에 억지로 넣으려던 계획을 전면 취소한다. **지금까지 작성한 이미지 번역 코드를 모조리 롤백하고, 기존 텍스트 번역 코드에 단 1줄의 버그도 남기지 않도록 `modules/image_translator/`에 비활성 상태로 격리해라. 텍스트 번역기를 v1.0.0으로 먼저 출시하고 이미지 번역은 추후 과제로 넘긴다.**"

---

## 5. 해결 과정 및 결과 (Resolution)

* **완벽한 성공이 아닌, 냉정한 실패 인정과 안전한 코드 롤백**:
  * AI가 작성했던 거짓 성공 보고서를 전면 폐기하고, 실패 원인을 명시한 점검 보고서를 작성.
  * 이미지 번역 관련 Content Script 주입 및 백그라운드 핸들러를 비활성화하고, 실험 코드를 `modules/image_translator/`로 안전하게 격리.
  * 기존의 텍스트 번역(Alt+A), 단어 사전 팝업, 다중 LLM 엔진 연동 기능이 어떤 사이드 이펙트도 받지 않도록 클린한 베이스라인 복원 완료.
