Web Translator 2.0은 다른 부가 기능을 배제하고, **오직 '마우스 호버 기반 이미지 내 텍스트 번역 (Image Translation)' 기능 하나에만 100% 집중**하여 개발합니다.

```
Web Translator 버전별 로드맵:
[v1.0.0 (출시 완료)] ──> [v2.0.0 (이미지 번역 단일 집중)] ──> [v3.0.0 (PDF 문서 번역)]
   • 텍스트/단어 인라인         • 호버 기반 이미지 번역 R&D 완성          • 브라우저 PDF 뷰어 번역
   • 다중 LLM / 다크모드       • WASM 메모리 및 좌표 정밀화
   • 옵션창 CSV 단어장
```

## 3. Web Translator 2.0 아키텍처 및 해결 방안

### 3.1 무거운 클라이언트 WASM 배제
* 브라우저 탭 메모리를 고갈시키는 클라이언트 온디바이스 WASM 모델 로드를 전면 배제.
* **Gemini 2.0 Flash Multimodal Native 번역 API**를 활용하여 원본 이미지와 텍스트를 인페인팅한 결과 이미지를 직접 수신하거나, 정밀 픽셀 좌표를 수신하는 초경량 통신 구조 채택.

### 3.2 DPI 및 CSS Transform 보정 정밀 Canvas 오버레이 렌더러
* 브라우저의 Device Pixel Ratio(DPR), CSS `object-fit`, `transform: scale()`, 패딩/마진을 정밀 계산하는 오버레이 엔진 구축.
* 텍스트 영역을 감쪽같이 지우는 **Inpainting Fill(배경색 자동 추정 정화)** 및 텍스트 폰트 자동 축소(Auto-scaling) 렌더러 탑재.

### 3.3 사용자 인터랙션 및 UX
* 웹페이지 내 이미지 호버 시 우측 상단에 미니멀한 `[번역]` 플로팅 버튼 노출.
* 번역 완료 후 `[원본 보기]` / `[번역 보기]` 원터치 토글 지원.
* 50px 미만의 웹 UI 아이콘/버튼은 자동 필터링하여 불필요한 번역 방지.
